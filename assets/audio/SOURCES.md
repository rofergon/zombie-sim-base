# Audio sources

All recordings in this directory are vendored so the game remains usable via
`file://`. Every source listed below was published under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), which permits
copying, modification and commercial use without attribution. Attribution is
included anyway to preserve provenance. Files were downloaded on 2026-08-30.

## OpenGameArt sources

- [100 CC0 SFX #2](https://opengameart.org/content/100-cc0-sfx-2) by
  rubberduck (`sfx_100_v2.zip`, CC0): machinery, construction, water, tension,
  door, stone and interface sounds.
- [100 CC0 metal and wood SFX](https://opengameart.org/content/100-cc0-metal-and-wood-sfx)
  by rubberduck (`100-CC0-wood-metal-SFX.zip`, CC0): hammer, tool and metal
  impacts.
- [Ambient Bird Sounds](https://opengameart.org/content/ambient-bird-sounds)
  by isaiah658 (`birds-isaiah658.ogg`, CC0).
- [Crickets Ambient Noise - loopable](https://opengameart.org/content/crickets-ambient-noise-loopable)
  by Wolfgang_ (`crickets.mp3`, CC0; the upstream page optionally credits Ted
  Kerr).
- [wind whoosh loop](https://opengameart.org/content/wind-whoosh-loop) by
  SketchMan3 (`wind woosh loop.ogg`, CC0).
